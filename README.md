# Классификация изображений: МРТ и жестовый язык

 классификация нетабличных данных (изображений).
Признаки извлекаются предобученной нейросетью **MobileNetV2**, затем на них обучаются
стандартные классификаторы sklearn и автоматическая система **LAMA (LightAutoML)**.

Во всех экспериментах `random_state = 42`, выборка делится 80% / 20% (`train_test_split` со `stratify`).

## Задачи

| | Задача | Данные | Классы |
|---|---|---|---|
| 1 | Есть ли опухоль на снимке МРТ (цель: F1 ≥ 0.85) | 253 снимка | 2 (`yes` - 155, `no` - 98) |
| 2 | Распознавание цифр жестового языка по фото руки | 700 фото | 10 (цифры 0-9, по 70 фото) |

## Подход

1. Снимок приводится к RGB 224×224 и нормализуется (`preprocess_input`).
2. `MobileNetV2(weights="imagenet", include_top=False, pooling="avg")` превращает каждое изображение в вектор из 1280 признаков.
3. Признаки масштабируются (`StandardScaler`, обучается только на train).
4. Обучаются 6 классификаторов: LogisticRegression, SVC, KNeighbors, RandomForest, GradientBoosting, MLP.
5. Отдельно обучается LAMA (`TabularAutoML`, `timeout=600`).
6. Модели сравниваются по метрикам на тесте и кросс-валидацией (5 фолдов).

## Результаты

### Задача 1: опухоль на МРТ (тест: 51 снимок)

| модель | accuracy | precision | recall | F1 |
|---|---|---|---|---|
| MLP | 0.922 | 0.966 | 0.903 | **0.933** |
| LAMA | 0.902 | 0.906 | 0.935 | 0.921 |
| LogisticRegression | 0.902 | 0.933 | 0.903 | 0.918 |
| SVC | 0.882 | 0.879 | 0.935 | 0.906 |
| RandomForest | 0.863 | 0.833 | 0.968 | 0.896 |
| GradientBoosting | 0.863 | 0.900 | 0.871 | 0.885 |
| KNeighbors | 0.843 | 0.960 | 0.774 | 0.857 |

Порог F1 ≥ 0.85 на тесте пройден всеми моделями. Тест небольшой (51 снимок), одна ошибка
сдвигает F1 примерно на 0.02, поэтому в ноутбуке приведена ещё и кросс-валидация.
По ней KNeighbors слабее остальных (F1 ≈ 0.79).

### Задача 2: цифры жестового языка (тест: 140 фото)

| модель | accuracy | F1 macro | F1 weighted |
|---|---|---|---|
| LogisticRegression | 1.000 | 1.000 | 1.000 |
| MLP | 0.993 | 0.993 | 0.993 |
| LAMA | 0.993 | 0.993 | 0.993 |
| RandomForest | 0.979 | 0.978 | 0.978 |
| SVC | 0.964 | 0.965 | 0.965 |
| KNeighbors | 0.950 | 0.950 | 0.950 |
| GradientBoosting | 0.950 | 0.950 | 0.950 |

**Оговорка:** фото в датасете сняты сериями, и соседние кадры почти одинаковы. Похожие фото
попадают и в обучение, и в тест, поэтому оценка завышена. На новых людях и при другом освещении
качество было бы ниже.

## Запуск

**Google Colab.** Загрузите `hw_mri_and_signs_colab.ipynb`, положите папки `yes`, `no` и архив с цифрами
на свой Google Диск, при необходимости поправьте пути в ячейках с данными и выполните **Runtime → Run all**
(около 25 минут, основное время - LAMA).

**Локально.** Нужен Python 3.9+ и пакеты:

```
pip install tensorflow scikit-learn pandas numpy matplotlib seaborn pillow lightautoml jupyter
```

Затем откройте `hw1_mri_tumor.ipynb` или `hw2_signs_multiclass.ipynb` в Jupyter (папки с фото должны лежать рядом).
Если файлы `features_*.npy` на месте, нейросеть заново не считается.

> На macOS LAMA может падать при многопроцессном чтении данных, поэтому в коде стоят `cpu_limit=1` и `n_jobs=1`.
